# 1. Kontext

Die Website soll langfristig wartbar, barrierearm und suchmaschinenfreundlich entwickelt werden. Eine semantisch korrekte HTML-Struktur verbessert die Verständlichkeit des Quellcodes für Browser, Suchmaschinen und unterstützende Technologien.

---

# 2. Entscheidung

Für alle Seiten und Komponenten von **s-bac.de** wird semantisches HTML verbindlich eingesetzt.

HTML-Elemente werden entsprechend ihrer fachlichen Bedeutung verwendet. Layoutzwecke werden ausschließlich mit CSS umgesetzt.

---

# 3. Begründung

Die Entscheidung bietet folgende Vorteile:

- Verbesserte Barrierefreiheit
- Bessere Suchmaschineninterpretation
- Höhere Wartbarkeit des Quellcodes
- Klarere Dokumentenstruktur
- Unterstützung moderner Webstandards

---

# 4. Betrachtete Alternativen

## Generische HTML-Strukturen

**Vorteile**

- Schnellere Entwicklung einzelner Seiten

**Nachteile**

- Schlechtere Lesbarkeit
- Eingeschränkte Barrierefreiheit
- Nachteile bei SEO und Wartbarkeit

Diese Alternative wurde verworfen.

---

# 5. Auswirkungen

- Überschriftenhierarchien werden konsequent eingehalten.
- Semantische Elemente wie `header`, `main`, `nav`, `section`, `article`, `aside` und `footer` werden bevorzugt verwendet.
- Komponenten werden regelmäßig auf semantische Korrektheit geprüft.
