# 1. Kontext

Für die Umsetzung von **s-bac.de** musste eine Entscheidung für ein Content-Management-System (CMS) getroffen werden. Das System soll eine effiziente Pflege der Inhalte ermöglichen und gleichzeitig die im Projekt definierten Anforderungen an Design, Struktur, Performance und Wartbarkeit unterstützen.

---

# 2. Entscheidung

Für das Projekt **s-bac.de** wird **Sitejet** als Content-Management-System eingesetzt.

Sitejet bildet die technische Grundlage für die Erstellung, Pflege und Veröffentlichung der Website. Individuelle Anpassungen erfolgen im Rahmen der definierten Architektur und des Designsystems.

---

# 3. Begründung

Die Entscheidung für Sitejet basiert auf folgenden Kriterien:

- Unterstützung der definierten Seitenstruktur
- Einfache redaktionelle Pflege
- Gute Integration individueller HTML-, CSS- und JavaScript-Komponenten
- Unterstützung responsiver Layouts
- Geeignet für kleine bis mittelgroße Unternehmenswebsites
- Effizienter Veröffentlichungsprozess

---

# 4. Betrachtete Alternativen

## Einsatz eines anderen CMS

**Vorteile**

- Größere Auswahl an Erweiterungen und Plugins

**Nachteile**

- Höherer Einrichtungs- und Wartungsaufwand
- Abweichung von der definierten Projektarchitektur

Diese Alternative wurde verworfen.

---

# 5. Auswirkungen

- Die technische Architektur orientiert sich an den Möglichkeiten von Sitejet.
- Individuelle Komponenten werden kompatibel zu Sitejet entwickelt.
- Inhaltspflege erfolgt innerhalb des CMS.
- Änderungen an der CMS-Strategie erfordern eine neue ADR.
