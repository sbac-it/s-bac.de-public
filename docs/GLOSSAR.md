# 1. Zweck

Dieses Glossar definiert die im Projekt verwendeten Fachbegriffe einheitlich.

Es dient als zentrale Referenz für alle Dokumente der Projektdokumentation und stellt sicher, dass Begriffe konsistent verwendet werden.

---

# 2. Begriffe

| Begriff | Definition |
|----------|------------|
| ADR | *Architecture Decision Record*. Dokumentiert eine Architekturentscheidung einschließlich Begründung und Auswirkungen. |
| Architektur | Gesamtheit der strukturellen und technischen Entscheidungen eines Systems. |
| Backlog | Priorisierte Liste offener Anforderungen, Aufgaben und Ideen. |
| Deployment | Bereitstellung einer neuen Version der Website in der Zielumgebung. |
| Dokumentationsportal | Gesamtheit aller Projektdokumente einschließlich Navigation, Glossar und ADRs. |
| Epic | Größere funktionale Anforderung, die mehrere Aufgaben oder Komponenten umfasst. |
| Git | Verteiltes Versionsverwaltungssystem zur Nachverfolgung aller Änderungen. |
| GitHub | Plattform zur Verwaltung des Git-Repositories sowie der Projektentwicklung. |
| Governance | Regeln und Prozesse zur Steuerung, Dokumentation und Qualitätssicherung des Projekts. |
| Komponente | Wiederverwendbarer Baustein der Website, z. B. Hero-Bereich, Karte oder Kontaktformular. |
| Markdown | Leichtgewichtige Auszeichnungssprache zur Erstellung strukturierter Dokumentation. |
| Repository | Verzeichnis, das Quellcode, Dokumentation und Projektdateien enthält. |
| Responsive Design | Gestaltung einer Website, die sich an unterschiedliche Bildschirmgrößen anpasst. |
| SEO | *Search Engine Optimization*. Maßnahmen zur Verbesserung der Auffindbarkeit in Suchmaschinen. |
| Semantic HTML | Verwendung semantischer HTML-Elemente zur Verbesserung von Struktur, Barrierefreiheit und SEO. |
| SiteJet | Ehemals für s-bac.de eingesetztes Content-Management-System; seit ADR-0012 nicht mehr Bestandteil des aktiven Veröffentlichungswegs. |
| Single Source of Truth (SSOT) | Grundsatz, dass jede Information genau eine verbindliche Quelle besitzt. |
| UI | *User Interface*. Die sichtbare Benutzeroberfläche einer Anwendung oder Website. |
| UX | *User Experience*. Gesamterlebnis eines Benutzers bei der Nutzung einer Anwendung oder Website. |
| Versionierung | Nachvollziehbare Verwaltung aller Änderungen an Dokumentation und Quellcode. |

Neue Fachbegriffe werden ausschließlich in diesem Glossar definiert und anschließend in den jeweiligen Dokumenten verwendet.
