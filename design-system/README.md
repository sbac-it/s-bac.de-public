# Design-System-Implementierung

Dieser Ordner enthält die führenden, technisch verwendbaren Artefakte des
s-bac.de-Designsystems. Die fachliche Spezifikation bleibt unter
`docs/design-system/` dokumentiert.

| Bereich | Führender Inhalt |
|---|---|
| `tokens/` | CSS Custom Properties und Design-Tokens |
| `components/` | wiederverwendbare Komponenten-Styles |
| `patterns/` | Layout- und Seitenmuster |
| `assets/` | Design-System-spezifische Icons und Medien |

Die Dateien in `src/styles/` verweisen auf diese Implementierungen. Änderungen
werden daher hier vorgenommen und nicht an den Verknüpfungen unter `src/`.
